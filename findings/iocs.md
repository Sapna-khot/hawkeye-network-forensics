# Indicators of Compromise (IoCs)

## Status

IoC identification is currently in progress.

No IP address, domain, email address, file hash, credential or other indicator is being classified as malicious at this stage without sufficient packet-level evidence.

## Investigation Sources

Potential IoCs will be investigated from:

- DNS queries
- HTTP requests
- SMTP communication
- External IP addresses
- Downloaded files
- Email content
- Network conversations
- Encoded or exfiltrated data

Confirmed IoCs will be added here as the investigation progresses.
